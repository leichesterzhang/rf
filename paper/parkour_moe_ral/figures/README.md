# Figures

Place final paper figures in this directory when you are ready to replace the boxed placeholders in `../main.tex`.

Recommended mapping:

- `framework.pdf` or `framework.png`: main method figure
- `terrain_suite.pdf` or `terrain_suite.png`: terrain gallery
- `qualitative.pdf` or `qualitative.png`: rollout snapshots
- `tsne.pdf` or `tsne.png`: gating/latent visualization

The current `main.tex` uses boxed placeholders instead of direct `\includegraphics`, so adding the real image files is optional until you are ready to switch each figure over.
